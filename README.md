# Brochure access test

Temporary GitHub Pages test for a two-page SLAI 2027 admissions brochure.

- `index.html`: bilingual viewing and download entry page.
- `brochure.pdf`: byte-identical copy of the supplied PDF.
- `previews/`: lightweight previews rendered from the PDF.
- `qrcode.png`: QR code pointing to the entry page.

This is a test publication on a personal account, not an institutional website.
No analytics, external fonts, or third-party page dependencies are used.

To update the brochure while keeping the same link, replace `brochure.pdf`,
refresh the previews, and push to `main`. Keep the repository and page path.

To remove the test, disable GitHub Pages and delete this test repository.
Deleting an individual PDF file alone does not remove it from Git history.
